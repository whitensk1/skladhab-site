# Концепция сайта фулфилмента для маркетплейсов

**Дата:** 2026-07-30  
**Эталоны:** [ffspace.ru](https://ffspace.ru/), mult.pro (на момент анализа недоступен / пустой ответ), плюс конкуренты: willbedone.pro, 360ff.ru, kitall, inpacks, fillru, ao-sdt и обзоры рынка.  
**Цель документа:** не «список сайтов», а **готовая продуктовая + маркетинговая + UX-концепция**, из которой можно сразу собирать лендинг и структуру сайта.

---

## 1. Что это за рынок (одним абзацем)

Селлер на WB / Ozon / Яндекс.Маркет платит за **снятие операционной боли**: забор с рынка/поставщика → приёмка → брак → ШК/ЧЗ → упаковка → FBO/FBS → возвраты. Сайт продаёт не «склад», а **предсказуемость unit-экономики + скорость + ответственность за ошибки**. Побеждает тот, кто за 30–60 секунд отвечает на три вопроса: *сколько будет стоить моя партия?*, *успею ли в слот?*, *кто платит, если накосячат?*

## 3. Что реально работает у FFSPACE (взять)

### 3.1. Оффер и доверие
- Три слова-якоря: **Быстро · Надёжно · Прозрачно** — но под ними нужны **цифры**, не иконки.
- Метрики на первом экране: *от N ₽/ед*, *отгрузки 2×/сутки*, *обработка от 2 часов*, *страхование склада*.
- **Оплата после факта / без депозита** — сильнейший дифференциатор для селлера с кэшфлоу.
- **Публичная оферта** вместо «подпишем договор через неделю» — снижает friction.
- **Партнёрство с Китаем/CHINASPACE** (если есть) — отдельный блок «забор с поставщика / из Китая».

### 3.2. Сегментация аудитории
Три карточки: **начинающий / средний / крупный** — с разным обещанием:
- новичок → «проведём за руку, без ошибок»;
- средний → «учёт + масштаб»;
- крупный → «индивидуальные условия + SLA».

### 3.3. Услуги «под ключ» (ядро оффера)
Обязательный набор блоков услуг (иконка + 1 строка + CTA «в расчёт»):
1. Приёмка + визуальный осмотр  
2. Отбраковка + маркировка (ШК / ЧЗ)  
3. Упаковка + комплекты  
4. FBO + FBS  
5. Возвраты и рекламации  
6. Допы: вкладыши, бирки, отпаривание, работа в ЛК МП  

### 3.4. Прайс
- Таблица **услуг с «от»** + кнопка «полный прайс» + **кнопка «пример расчёта»**.
- Шкала объёма (как у FFSPACE в FAQ): 1–100 / 100–300 / … → ₽ за ед. — селлер сразу кладёт в unit-экономику.

### 3.5. FAQ, который продаёт
Не общие «что такое фулфилмент», а:
- какой минимум партии (у FF — **от 1 шт**);
- что нужно для **точного расчёта** (чек-лист из 10+ полей — это gold);
- запрещённые категории;
- склады, на которые возите;
- работа из другого города / из-за рубежа.

### 3.6. CTA-механика
- Sticky / popup: **«Быстрый расчёт»** (имя + телефон + комментарий).
- Пример запроса прямо в форме: *«500 мини-принтеров, zip, 2 ШК, визитка, WB Коледино»* — учит клиента писать ТЗ.

## 5. Слабые стороны рынка (сознательно убрать у себя)

1. **Водяной SEO-подвал** на 3000 знаков «что такое фулфилмент» без структуры — вредит конверсии, SEO можно закрыть отдельными статьями.  
2. **Одинаковые иконки «быстро-качественно-недорого»** без цифр и SLA.  
3. **Цены только «от X ₽»** без сценариев и минимума/максимума партии.  
4. **Нет ответа на «а если вы накосячите?»**  
5. **Нет фото склада / команды / процесса.**  
6. **Форма «оставьте заявку»** без примера ТЗ — приходят мусорные лиды.  
7. **Смешение 15 услуг** (Китай + SEO + самовыкупы + фулфилмент) без иерархии — размывает доверие.  
8. **Медленный / тяжёлый Tilda** с кучей анимаций — селлер с телефона уходит.  
9. **Дублирующие блоки** (одно и то же «прозрачность» 4 раза).  
10. **Слабая мобильная структура** (длинный скролл без якорей и sticky CTA).

## 6. Позиционирование вашего сайта (рекомендация)

### Формула оффера (черновик)
> **Фулфилмент для WB и Ozon в Москве:**  
> приёмка → маркировка → упаковка → FBO/FBS **с понятной сметой за 20 минут**,  
> **оплатой по факту** и **компенсацией ошибок по регламенту**.

### Обещание (одно главное)
**«Вы знаете цену партии до старта и видите статус в процессе — без сюрпризов на отгрузке.»**

### Для кого
- **Primary:** селлеры 100–15 000 ед/мес (одежда, косметика, гаджеты, дом).  
- **Secondary:** новички с первой поставкой с Садовода / ЮВ / Китая.

### Не для кого (честно на сайте)
- КГТ сверх лимитов (если не возите).  
- Запрещённые категории (список).  
- Обещания «самого дешёвого в Москве» без unit-экономики.

## 8. Структура главной страницы (блочный каркас)

Порядок = приоритет конверсии. Каждый блок: **заголовок → proof → CTA**.

### Блок 0. Шапка
- Лого, тел, Telegram/WhatsApp, «Прайс», **кнопка «Рассчитать»** (всегда видна на mobile sticky).

### Блок 1. Hero
- H1: *Фулфилмент для Wildberries и Ozon в Москве*  
- Подзаголовок: *смета за 20 минут · оплата по факту · FBO и FBS*  
- 3–4 метрики: `от X ₽/ед` · `обработка от 2 ч` · `N отгрузок/сутки` · `склад застрахован`  
- CTA primary: **Получить расчёт**  
- CTA secondary: **Смотреть прайс** / **Открыть калькулятор**  
- Trust row: логотипы WB · Ozon · ЯМ · (опц. ЭДО)

### Блок 2. Боль селлера → решение (3–4 карточки)
- «Не успеваю в слот» → сроки обработки  
- «Боюсь пересорта и штрафов» → контроль + компенсация  
- «Непонятно, сколько выйдет» → сметы и прайс  
- «Нет времени на упаковку» → полный цикл  

### Блок 3. Кому подходит
Три сегмента (как FFSPACE) + 1 строка «не берём: …».

### Блок 4. Услуги (ядро)
5–6 карточек процесса + ссылка «все операции в прайсе».

### Блок 5. Как это работает (6 шагов)
1. Заявка / ТЗ  
2. Смета и согласование  
3. Забор или привоз  
4. Приёмка + обработка  
5. Отгрузка FBO/FBS  
6. Отчёт + оплата по факту  

### Блок 6. Цены «по-честному»
- Мини-таблица топ-10 операций  
- **3 готовые сметы** (малый / средний / объём)  
- Ссылка на полный прайс  
- Шкала ₽/ед от объёма  

### Блок 7. Ответственность и SLA
- Таблица: ошибка → кто платит  
- «Штраф МП по нашей вине — компенсируем» (если реально можете)  
- Фото/видео фиксация  

### Блок 8. Склад и безопасность
- Адрес, режим, м², температура  
- Камеры 24/7, охрана, страховка  
- **Реальные фото** (6–12), не сток  

### Блок 9. Технологии (если есть)
- WMS / ЛК / Telegram-статусы / интеграции МП / ЧЗ  
- Скриншоты > слова  

### Блок 10. Отзывы
- Имя, площадка (WB/Ozon), срок, конкретика («4 поставки», «FBS»)  
- Виджет Яндекс/2ГИС, если есть  

### Блок 11. FAQ (8–12 вопросов)
Обязательно: минимум партии, чек-лист для сметы, FBS/FBO, склады, запреты, регионы, сроки, хранение.

### Блок 12. Финальный CTA
- Повтор формы + пример ТЗ  
- Контакты: тел, TG, WhatsApp, email, карта  

### Блок 13. SEO (коротко)
1 экран текста с H2/H3 **или** вынести в блог — не дублировать всю страницу.

## 9. Контент-правила (тон и тексты)

| Делать | Не делать |
|--------|-----------|
| Конкретика: «2 отгрузки FBS в сутки», «смета 20 мин» | «Индивидуальный подход мирового уровня» |
| Глаголы действия: «заберём, промаркируем, отгрузим» | «Оказываем комплекс услуг» |
| Цифры и «от» + сценарий | Только «цена по запросу» |
| Честные ограничения | Обещать всё подряд |
| Один главный CTA на экран | 5 разных кнопок с разным смыслом |

**Микрокопи формы:**
- Поля: Имя · Телефон · Telegram (опц.) · «Опишите партию» (placeholder с примером) · чекбокс оферты/ПДн  
- Кнопка: **Получить смету** (не «Отправить»)  
- После отправки: «Ответим в Telegram/WhatsApp за N минут в рабочее время»

## 10. Конверсионная механика (воронка)

```
Реклама / SEO / сарафан
        ↓
Hero (30 сек) → «похоже, моё»
        ↓
Сметы / прайс / калькулятор → «примерно понятна цена»
        ↓
Форма с примером ТЗ → качественный лид
        ↓
Менеджер 20 мин → точная смета
        ↓
Оферта + первая поставка (бонус: скидка/бесплатная приёмка N ед.)
        ↓
Повторные поставки + реферал
```

**Бонус первой поставки** (как у сильных игроков):  
«Первым 10 / в июле: бесплатная приёмка 500 ед. или −30% на хранение 1-й месяц» — только если экономика позволяет.

## 11. Дизайн-система (кратко)

- **Стиль:** B2B-clean, много воздуха, крупная типографика, тёмно-синий/графит + 1 акцент (оранжевый/лайм для CTA).  
- **Не:** кислотный Tilda-хаос, 3D-смартфоны на каждом блоке, бесконечные Lottie.  
- **Обязательно:** mobile-first, sticky «Рассчитать», якорное меню на desktop.  
- **Доказательства:** фото склада 16:9, табличные блоки, иконки outline одной толщины.  
- **Скорость:** ≤ 2.5 s LCP на 4G; изображения WebP; минимум сторонних виджетов.

## 14. Итоговая «одна концепция» (резюме на 30 секунд)

Ваш сайт — **не витрина склада**, а **инструмент принятия решения селлера**:

1. **Сверху** — цифры, FBO/FBS, Москва, оплата по факту.  
2. **В середине** — услуги + **понятные цены** (таблица + 3 сметы) + процесс.  
3. **Ниже** — **ответственность, склад, отзывы, FAQ**.  
4. **Везде** — один путь: *описать партию → получить смету*.  

Берём у **FFSPACE**: сегменты, оферта, оплата по факту, детальный FAQ, «от N ₽», забор с рынков, 2× FBS.  
Берём у **willbedone / топа рынка**: сценарные сметы, матрицу ответственности, proof контроля, WMS-скрин, ЧЗ, жёсткий trust.  
Выкидываем: воду, дубли, фейковую «уникальность», размытие в 20 услуг, цены без контекста.

1. Утвердить **название бренда**, город/адрес склада, реальные цифры (₽, часы, страховка).

3. Сверстать **лендинг по блокам §8** (Tilda / Webflow / Next.js — на выбор).  
4. Подключить форму → Telegram-бот / amoCRM.  
5. Запуск рекламы: «фулфилмент WB Москва», «FBS упаковка», ретаргет на /price.
