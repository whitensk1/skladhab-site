```
Понял, что это моё (hero)
```

### Q-06. Калькулятор
**Статус:** ждём информацию  
**Где на сайте:** `/calculator` или виджет на главной /price  

**Что нужно, чтобы сделать калькулятор (не «красивую форму»):**

1. **Формула расчёта** (псевдокод или таблица):
   - какие поля ввода
   - какие строки прайса суммируются
   - множители (вес, габариты, сложность)
2. **Поля UI (предложение по умолчанию — подтвердить):**
   - маркетплейс: WB / Ozon / ЯМ
   - схема: FBO / FBS
   - количество SKU / единиц
   - тип товара (влияет на упаковку)
   - нужен ли брак-контроль
   - маркировка: ШК / ЧЗ
   - тип упаковки
   - склад назначения (или «любой МО»)
   - нужен ли забор груза + зона
3. **Ограничения:** max вес, max габариты, что считаем «индивидуально»
4. **Вывод:** «ориентир от–до» vs «точная смета» + дисклеймер
5. **Куда уходит лид** после расчёта (Telegram, CRM, email)
6. **MVP калькулятора:** квиз → «ориентир» + заявка **или** полноценный прайс-движок

**Блокирует MVP сайта:** нет  
**Блокирует фичу калькулятора:** да  
**Fallback MVP:** multi-step форма «Опишите партию» (не считает ₽ сама) + дисклеймер «менеджер пришлёт смету за {{QUOTE_SLA_MINUTES}} мин».

**Временный UX-копирайт:**
> Калькулятор в разработке. Оставьте параметры партии — посчитаем вручную за {{QUOTE_SLA_MINUTES}} минут.
