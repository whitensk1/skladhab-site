# SEO: что сделано на сайте и что сделать вам

Сайт: **https://fbo-fbs.ru**  
Без панелей Яндекс/Google код помогает индексировать, но **не заменяет** регистрацию в Вебмастере и Search Console.

---

## 1. Уже на сайте (техническое SEO)

| Элемент | Файл / место |
|--------|----------------|
| Title, description, keywords | `index.html` `<head>` |
| robots: index, follow | meta + `robots.txt` |
| Canonical, hreflang ru | `https://fbo-fbs.ru/` |
| Open Graph / Twitter | картинка `media/brand/og-cover.jpg` |
| Schema.org JSON-LD | Organization, LocalBusiness, WebSite, WebPage, Service, **FAQPage** |
| Карта сайта | `https://fbo-fbs.ru/sitemap.xml` |
| robots.txt | `https://fbo-fbs.ru/robots.txt` |
| PWA-манифест | `site.webmanifest` |
| FAQ с ключами FBO/FBS/ЧЗ/МР | блок «Частые вопросы» |
| SEO-текст + ссылки по разделам | футер `#seo-text` |
| NAP (название, адрес, email) | футер, microdata |
| Alt у фото шагов | осмысленные подписи |

Проверка в браузере:
- https://fbo-fbs.ru/robots.txt  
- https://fbo-fbs.ru/sitemap.xml  
- «Просмотр кода» → `application/ld+json`

## 2. Обязательно с вашей стороны (1–2 часа)

### А) Яндекс.Вебмастер
1. https://webmaster.yandex.ru → **Добавить сайт** → `https://fbo-fbs.ru`
2. Способ: **Meta-тег** или HTML-файл  
3. Пришлите код вида `yandex-verification` content="...." — вставим в `index.html`
4. **Индексирование → Файлы Sitemap** → `https://fbo-fbs.ru/sitemap.xml`
5. **Индексирование → Переобход страниц** → главная
6. **Настройки → Регион сайта** → Москва (если доступно)
7. Позже: **Диагностика** → нет ли «не индексируется»

### Б) Google Search Console
1. https://search.google.com/search-console → ресурс URL-префикс `https://fbo-fbs.ru`
2. Подтверждение **HTML-тег** → код `google-site-verification` — пришлите, вставим
3. **Файлы Sitemap** → тот же sitemap.xml
4. **Проверка URL** → `https://fbo-fbs.ru/` → **Запросить индексирование**

### В) Локальный бизнес (сильно для «Москва»)
1. https://business.yandex.ru — карточка организации  
2. Адрес: Волоколамское ш., 73, Москва  
3. Сайт: https://fbo-fbs.ru  
4. Телефон / режим 24/7  
5. По возможности 2ГИС

### Г) Яндекс Метрика / Google Analytics (по желанию)
Счётчики ≠ SEO-позиции, но показывают трафик.  
Если дадите ID Метрики — можно встроить (РФ, без Google).

## 3. Как проверить, что «подхватили»

Через 3–14 дней (иногда дольше):

```
site:fbo-fbs.ru
```
в Яндексе и Google.

Должна появиться главная; позже — `privacy.html`.

## 4. Чего ждать по позициям (честно)

| Запрос | Ожидание |
|--------|----------|
| `fbo-fbs.ru`, «успешное дело фулфилмент» | быстрее |
| «фулфилмент москва», «fbo fbs» | конкуренция, месяцы + ссылки + контент |
| Один только код без ссылок и карточек | слабый рост |

Техника на сайте — **база**. Рост = Вебмастер + карты + отзывы + статьи/кейсы + естественные ссылки.

## 5. Что ещё можно усилить позже

1. Отдельные посадочные: `/fbo`, `/fbs`, `/chestny-znak` (или якоря + тексты)
2. Блог: 5–10 статей под запросы
3. Кейсы клиентов (с разрешения)
4. Микроразметка Product/Offer, если появится прайс
5. CDN / ещё сжатие (скорость = фактор ранжирования)

---

## 6. Не делать

- Куча скрытого текста и «масло масляное» ключей  
- Покупные ссылки с ГС  
- Дубли сайта на github.io как основной (canonical уже на fbo-fbs.ru)

Старый GitHub Pages лучше не продвигать; в Search Console основной — **только fbo-fbs.ru**.

---

## 7. Контакты для вставки кодов

Пришлите в чат (можно по отдельности):

```
yandex-verification: ________
google-site-verification: ________
```

Вставим в `<head>` и зальём на хостинг.
